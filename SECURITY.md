# Security Policy

## Supported Version

Security fixes are applied to the latest release on the `main` branch.

## Reporting a Vulnerability

Please do not publish credentials, customer data, database exports, or a
working exploit in a public issue.

Report vulnerabilities privately through GitHub's private vulnerability
reporting feature. Include the affected route or component, reproduction
steps, expected behavior, and the potential impact.

## Deployment Responsibility

This repository contains demo-safe application code. Production operators are
responsible for secure environment configuration, HTTPS, backups, access
control, mail and queue credentials, database permissions, and timely
dependency updates.
