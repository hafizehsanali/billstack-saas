# Changelog

All notable public releases of Zephrant ERP are documented here.

## [1.0.0-public] - 2026-06-07

### Added

- Multi-tenant inventory, billing, purchasing, customer, and supplier flows
- POS billing, sales returns, purchase returns, and stock movement ledger
- Customer and supplier account statements with payment allocation
- Dashboard analytics, business reports, low-stock alerts, and invoice PDFs
- Business branding settings and demo-safe seed data
- Automated feature coverage for accounting, inventory, tenancy, and forms
- GitHub Actions verification for PHP tests, frontend builds, and advisories

### Stabilized

- Tenant-scoped validation and transaction numbering
- Payment and return effects on account balances
- Stock restoration and reversal rules
- Cancellation safeguards for financial records
- Responsive transaction and statement interfaces
- Public setup, architecture, security, and repository documentation
